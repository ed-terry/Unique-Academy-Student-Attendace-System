## About Unique Academy Student Attendance System

This Laravel application has been adapted for Unique Academy and NACTVET NTA Level 5 ICT. It supports student attendance tracking, schedule management, late-time monitoring, and attendance reporting.

## Major Technologies

- HTML5
- CSS
- JavaScript
- Bootstrap
- PHP
- Laravel

## Local Setup

1. Copy `.env.example` to `.env`
2. Configure database and mail settings
3. Run `composer install`
4. Run `php artisan key:generate`
5. Run `php artisan migrate`
6. Run `php artisan db:seed`

### Install & Setup

To setup and run the Unique Academy Student Attendance System locally, follow these steps:

```
$ git clone <your-project-repository>
$ cd Student\ Attendance\ Management\ System
$ composer install
$ cp .env.example .env
$ php artisan key:generate
$ php artisan migrate
$ php artisan db:seed
$ php artisan serve
```
